# C Ray-Tracer (based on Ray Tracing in One Weekend, 6.1)

***This code was written by an idiot and should not be used in any professional project***

A simple ray-tracer written in pure C, built following the book **Ray Tracing in One Weekend** by Peter Shirley, up until Chapter 6.1. Perhaps I'll continue it some day, but I've had too much of the pain of translating C++ OOP to pure C for now.

## Compiling

Just:

